# Auto Fury LLC Website

This project is a modern static website built for **Auto Fury LLC**, a U.S.-based vehicle transport company.  
It showcases the company’s services, gallery, and contact information in a responsive, mobile-friendly layout.

---

## 🧱 Overview

The website includes:
- **Home**, **How It Works**, **Why Choose Us**, **Gallery**, **FAQ**, and **Contact** pages
- A **Request a Quote** form that submits securely via [FormSubmit.co](https://formsubmit.co)
- A **responsive gallery** built with [GLightbox](https://github.com/biati-digital/glightbox)
- Optimized **Bootstrap 5** layout and components
- SEO-ready titles, meta descriptions, and a favicon

---

## 🖼️ Gallery

The gallery features dozens of photos of vehicles shipped by Auto Fury LLC, loaded dynamically with:
- `images/` — main gallery images (e.g., `11.JPG`, `42.JPG`, `43.JPG`)
- `images/NewPictures/` — additional categorized photos (`n3.JPG`–`n31.JPG`, `m1.JPG`–`m4.JPG`, `p1.JPG`–`p35.JPG`)

Each image opens in a **lightbox** with zoom and navigation controls.

---

## ⚙️ Tech Stack

- **HTML5 / CSS3 / JavaScript**
- **Bootstrap 5.3 (via CDN)**
- **Bootstrap Icons**
- **GLightbox (for image modals)**
- **FormSubmit** for backend-free email handling
